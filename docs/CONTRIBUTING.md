# Contributing

1. Open an issue for significant behavior or data-model changes.
2. Work on a focused branch.
3. Keep presentation, domain rules, API access, and styles in their intended modules.
4. Add tests and update documentation.
5. For electoral data, include source URLs, dates, validation notes, and verification status.
6. Never commit credentials or personal voter information.
7. Open a pull request and describe the checks actually performed.
