# Frontend source layout

Create the modules below as the actual deployed source is ported. Keep the scaffold descriptive until the real framework, package manifest, and source files are available.

- `app/`: entry point, routing, providers.
- `components/common/`: reusable generic UI.
- `components/navigation/`: header, breadcrumbs, back navigation.
- `components/districts/`: district directory and dashboard widgets.
- `components/constituencies/`: constituency lists and detail components.
- `components/maps/`: map presentation, controls, attribution.
- `layouts/`: shared page shells.
- `pages/`: route-level views.
- `features/electoral-data/`: domain rules, schemas, selectors.
- `services/`: API client and provider adapters.
- `hooks/`, `types/`, `data/`, `styles/`: shared utilities, contracts, labelled fixtures, and styles.
